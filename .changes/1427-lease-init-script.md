### Added

- **`@reticlehq/server` — a leased tab can now stub the host bindings a desktop shell injects.** A Wails view calls `window.go.main.App.*` on mount, a Tauri view expects `window.runtime`, an Electron renderer expects a preload object. In a leased tab those bindings never exist. The view threw on mount, and nothing in it could be verified. The only workaround was to launch your own Chrome with remote debugging and inject a stub over raw CDP. `reticle_lease { action: "acquire", initScript: "<js>" }` installs the script before any page script runs, for that lease only, and disposes it with the lease. Every verdict on that lease carries a note that a stub was installed, so a green is never read as one about the real shell. Closes [#1427](https://github.com/reticlehq/reticle/issues/1427).
